# 계산한번에 — 무료 생활 계산기 사이트

## 실행하기
`index.html`을 크롬 등 브라우저에서 열면 즉시 사용할 수 있습니다. 서버나 별도 설치가 필요하지 않습니다.

## 포함된 기능
- 퍼센트: 비율, 일부 값, 증감률, 할인 가격
- 대출: 원리금균등/원금균등 상환액 및 총이자
- 날짜: 날짜 차이, 주 환산, 시작/종료일 포함 여부
- 반응형 디자인, 개인정보 안내 페이지

## 배포하기
Cloudflare Pages 또는 GitHub Pages 같은 정적 웹 호스팅에 **이 폴더의 4개 파일을 모두** 업로드할 수 있습니다. 도메인을 연결하기 전에는 제공 업체의 상업적 이용 정책을 확인하세요.

## 광고 수익화 전 해야 할 일
1. 실제 도메인 및 운영자 연락 경로 마련.
2. 사이트 설명·사용법·예시와 유용한 콘텐츠 추가.
3. 사이트 운영 정책 및 개인정보 처리 안내를 실제 배포 환경에 맞게 수정.
4. 광고 서비스 승인 신청 후 광고 정책을 준수하여 코드 추가.
5. 사이트맵, 검색엔진 등록, 유입 분석 등 검색 최적화 작업.

현재 광고 코드가 없으며, 광고 승인이나 수익을 보장하지 않습니다. 실제 금융상품 계산과 다를 수 있으므로 참고용입니다.
